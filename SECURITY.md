# Güvenlik politikası

Bir güvenlik açığı bulduysanız lütfen herkese açık bir issue açmayın; **GitHub → Security → Report a vulnerability** (özel güvenlik bildirimi) kullanın. İletişim bilgisi `/.well-known/security.txt` dosyasında da yer alır.

- 72 saat içinde yanıt verilir.
- Yalnızca bu depoya ve `*.azurestaticapps.net` üzerindeki kendi ürün adresimize yönelik iyi niyetli testler kabul edilir. Veri sağlayıcıya (CISA) ve üçüncü taraflara yönelik testler kapsam dışıdır.
